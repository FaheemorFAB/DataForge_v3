# 🛠️ DataForge v3

**DataForge** is an end-to-end automated data engineering, analytical profiling, and machine learning platform. It empowers teams and researchers to seamlessly ingest raw spreadsheets and database tables, execute automated data cleaning pipelines, perform comprehensive statistical exploratory data analysis (EDA), train predictive models with competitive AutoML tournaments, and produce publication-ready reports—all with zero code required.
